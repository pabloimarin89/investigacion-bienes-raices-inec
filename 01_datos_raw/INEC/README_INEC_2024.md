# INEC — Estadísticas de la Construcción 2024

La base oficial 2024 se obtiene desde el Catálogo de Metadatos y Microdatos del INEC.

Estudio:
Estadísticas de la Construcción 2024 Definitivo
ID: CRC-INEC-ECONS-2024

Página:
https://sistemas.inec.cr/nada5.4/index.php/catalog/376

Importante:
El catálogo exige iniciar sesión para descargar los microdatos, aunque el archivo esté clasificado como de uso público.

Una vez descargado:
1. Guardar el archivo original en esta carpeta.
2. No modificarlo ni renombrar columnas.
3. Preferiblemente incluir `2024` en el nombre del archivo.
4. Ejecutar `03_scripts_R/01_importacion_INEC.R`.

El script admite:
- CSV
- XLS / XLSX
- SAV
- DTA

La versión pública definitiva reporta 37.044 registros y 17 variables.
